# Three-Phase Motor Control – PLC Wiring

Three-phase conveyor motor control circuit built in AutoCAD Electrical. Covers motor starter wiring (disconnect, contactor, overload) and PLC digital I/O for start/stop control.

This is a guided build based on [this tutorial](https://www.youtube.com/watch?v=7QQRG2sLbYk), not an original design. Built to practice reading and drawing industrial control schematics.

## What's included

- Motor power circuit: 3-phase disconnect, contactor, overload protection to conveyor motor
- Control circuit: 480V to 120V control transformer, start/stop pushbuttons, contactor coil control
- PLC I/O: digital input wiring for PLC rack (start, stop, running status)

- AutoCAD Electrical
